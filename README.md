# Disney+ Hotstar Content Analytics Dashboard

An interactive Business Intelligence dashboard built using **Power BI** to analyze streaming content trends, catalog distribution, and audience ratings on Disney+ Hotstar.

## Project Overview
This project explores the platform's movie and TV show catalog to uncover insights regarding content growth over the years, genre popularity, regional distribution, and content ratings.

## Key Features & Insights
* **Catalog Breakdown:** Visualized the total volume of movies versus TV shows available on the platform.
* **Genre & Rating Analysis:** Examined top-performing genres and categorized content by age ratings to understand target demographics.
* **Temporal Trends:** Tracked content release years and addition trends over time using custom Power BI visuals.

## Tools & Technologies Used
* **Power BI Desktop** (Data Modeling, DAX, Power Query)
* **Data Visualization** (Custom color palettes, KPI cards, slicers)

## How to View
1. Download the `.pbix` file from this repository.
2. Open it using **Microsoft Power BI Desktop** to interact with the filters, pages, and data model.
